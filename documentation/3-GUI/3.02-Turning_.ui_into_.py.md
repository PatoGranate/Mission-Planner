Having completed your first design of your GUI, you will now want to be able to edit it in python, in order to add functionality to its buttons and other widgets. In order to do this, navigate to the current directory using the typical cd: "Users:.xxxxx/xxx" command line, and once in the correct directory, the following can be done: 

```terminal
pyuic5 -x YourExistingUIFileName.ui -o YourDesiredPythonFileName.py
```

This line takes the .ui file in which your UI has been designed, and turns it into a python file which specifies that exact same window. We can later extract the Ui_MainWindow class from this python file in order to add functionality to it without changing the file directly. It is important not to want to write functionality in this file directly (even though this is theoretically possible, and will work), because every time you edit the UI in the designer, and run the line above to get it working in python, you will overwrite the code you have added to the file, and if you are editing the UI frequently to add little tweaks (which are necessary and normal), you will have to re-write the same code over and over.

Instead, a new python file can be created, in which we can do the following:

```python
from PyQt5 import QtWidgets
from src.gui.MainUI import Ui_MainWindow

class MainWindow(QtWidgets.QMainWindow, Ui_MainWindow):
    def __init__(self):
        # Initiate window
        super().__init__()
        self.setupUi(self)
```

doing this will take the Ui_MainWindow class which has been automatically created in the python file earlier, and initialize it in the new python file (Remember to change gui.MainUI to your .py name you specified earlier)
