### Pre-requisites
Before getting started with the GUI side of the program, it is useful to have already gotten some functionality working. Without basic functionality already developed, it is difficult to gauge how large your application is going to be, which makes it hard to design a well-laid-out GUI, as you will want to add new buttons and functionality as you develop the back-end.

PyQt5 has a drag and drop designer, which can be installed and is very intuitive to use. Main windows allow you to create a blank page, in which buttons, labels etc. can be placed and organized into the sizes and positions that you want. 

It is important to understand how grid layouts work, as these are very useful but can be confusing when starting out. Grid layouts make the contents inside the grid fill up the entire page/frame/box in which they are being laid out, which means that some widgets cannot be resized to exact sizes. However, individual widgets have minimum and maximum sizes which can be specified from the property editor, as well as their behaviour inside the grid. For instance, maximum (counterintuitively) makes the widget be as small as possible, and expanding makes it expand.
