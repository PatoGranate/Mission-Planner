In order to have your observer satellite point in the direction of your target, the positions of both satellites must be known at the timestep of interest. It is useful to know when pointing is required, in order to avoid computationally expensive operations when they are unnecessary. Requirements for pointing can be found [[2.02-Cross_Satellite_Operations|here]].

Once a timestamp has been identified in which targeted pointing is necessary, the attitude of the satellite can be computed in much the same way as it was computed for nadir pointing when setting up the satellite. 

In order to know where to point, we need to know the positions of both satellites at the timestep of interest, in an earth centred inertial frame of reference, such that the positions do not change with respect to the earths rotation. The normal target vector can be defined simply as the difference between the two satellite positions, such that:

```python
# Calculate the unit vector nadir pointing at t = 0
target_vector = Vector3D(float(target_pos[0] - observer_pos[0]),
                         float(target_pos[1] - observer_pos[1]),
	                     float(target_pos[2] - observer_pos[2]))

target_vector_mag = target_vector.getNorm()

b3_unit = target_vector.scalarMultiply(1/target_vector_mag)
```

With this vector defined, the same process can be followed as in [[2.01-Rotations_and_Quaternions]], where 

```python
# Find the velocity vector and normalize it
vel = satA.get_vels(times)
vec_vel = Vector3D(float(vel[idx,0]),
				   float(vel[idx,1]),
				   float(vel[idx,2]))

b1 = vec_vel.subtract(b3_unit.scalarMultiply(vec_vel.dotProduct(b3_unit)))
b1_unit = b1.scalarMultiply(1/b1.getNorm())

# Define the remaining vector as the orthogonal to b3 and b1
b2_unit = b3_unit.crossProduct(b1_unit)

DCM_b2e = np.array([(b1_unit.x, b1_unit.y, b1_unit.z), 
					(b2_unit.x, b2_unit.y, b2_unit.z), 
					(b3_unit.x, b3_unit.y, b3_unit.z)])
```

Once the vector matrix has been found, the quaternion can be extracted. Moreover, the previously defined quaternion array can be altered to include the new quaternion as follows:

```python 
quat = R.from_matrix(DCM_b2e).as_quat()
quats[idx] = quat # Where idx is the index of time for pointing
```
